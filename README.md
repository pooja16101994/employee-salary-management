# Employee Salary Management Assessment

A full-stack salary management dashboard built with React + TypeScript on the frontend and Express + TypeScript + SQLite on the backend.

## Tech Stack Recommendation
For this assessment, the strongest stack is:
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express + TypeScript
- Database: SQLite (for 10,000 employees, local and easy to run)
- Tests: Vitest

This is the best fit because it matches the role, minimizes setup overhead, and keeps the solution production-quality without introducing Python unnecessarily.

## Features
- Salary dashboard for HR review
- Filters by country, department, and role
- Search across employee names and email
- Summary analytics for payroll, average salary, and top departments
- Seed data for 10,000 employees

## Run locally
1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open the frontend at http://localhost:5173
4. Backend runs at http://localhost:5001
